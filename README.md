## 🚀 Overview

This repository houses the **custom-built, interactive presentation** for the Academy of Excellence 3D Web Application project. Instead of using traditional, static PowerPoint slides, this presentation was engineered from the ground up using **React**, **Tailwind CSS v4**, and **Framer Motion** to deliver a cinematic, high-end tech keynote experience.

## 🌟 Key Features

- **🎬 Cinematic Transitions:** Smooth, physics-based `<AnimatePresence>` transitions between every slide.
- **💻 Hacker Typing Effects:** Real-time character-by-character typing animations for PHP code blocks to simulate a live terminal.
- **🔄 Live Data Flow Diagrams:** Animated SVG pathways demonstrating real-time JSON payload transfers from React → PHP → HubSpot Webhooks.
- **📱 Simulated UI Mockups:** 3D animated CSS mockups including a functional-looking WhatsApp chat interface and incoming CRM leads.
- **🎨 Glassmorphism & Neon UI:** Designed with a premium dark-mode aesthetic, featuring deep blurs, infinite spinning gradients, and glowing accents.

## ⚡ Quick Start

To run this presentation locally:

```bash
# 1. Clone the repository
git clone https://github.com/your-username/academy-presentation.git

# 2. Navigate to directory
cd academy-presentation

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

> **Navigation Tip:** Navigate to `http://localhost:5173` in your browser. Use the **Left/Right Arrow Keys** or the on-screen glowing buttons to smoothly transition between slides.
